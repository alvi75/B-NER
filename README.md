Named Entity Recognition (NER) is a trendy topic in today's era as it automatically identifies and classifies named entities into various predefined categories. Though a lot of research has been done in this field, some problems still need to be solved. It helps to speed up search indexing by removing unnecessary named entities. Still, it also helps with text classification, customer support (e.g., chatbots), content recommendation, semantic annotation, sentiment analysis, and more. In this paper, we introduced the largest Bangla NER (B-NER), a well-defined fine-grained dataset consisting of 22,144 manually annotated Bangla sentences collected from Bangla newspaper and Bangla Wikipedia. While in low-resource languages, such as in Bangla Language Processing (BLP), recent works are explicitly done on three familiar entities: person, location, and organization; B-NER contains diverse 8 entities named: person, geographical, organization, geopolitical, time indicator, artifact, natural phenomenon, and event. This dataset is more complex than current Bangla NER datasets since it contains a broader range of entities that better represent real-world applications. We present the dataset properties, the statistics of the datasets, an overview of the annotation guidelines, illustrated with examples, and present an analysis of the inter-annotator agreement. Furthermore, we compare our data sets to those of other publicly-accessible datasets to demonstrate their excellent quality. We implement several state-of-the-art baselines for benchmark evaluation and extend the recent multilingual pre-trained model m-BERT technique that gives noticeable results of micro 97\% accuracy and macro 86\% accuracy. We also evaluated the base versions (12-layer) of Multilingual BERT, indicBERT, Electra, BI-LSTM, BILSTM-CRF and BiLSTM with Character Embedding for comparison. Moreover, Our experiments show that Indic-BERT achieves state-of-the-art performance over most of the tasks in Bangla NER. We release our dataset and baselines under a CC-BY 4.0 license in the CoNNL-2002 format to facilitate future work on fine-grained NER for Bangla.
